# life-log-template

一个用**文件夹 + Git** 记录自己、并让 AI 定期分析的模板。

不是日记 app，不是软件。就是一堆 markdown 文件，加三条约定。

---

## 为什么是这个形态

- **记录的成本必须接近零**，否则三周就停。
- **分析的价值不在写得多长**，在"同一组变量连续记了多久"。
- **app 会死，文件不会。** `git log` 还顺便给你一份"我做过什么"。

---

## 三步上手

1. **Fork / 克隆**这个仓库，**改成 private**（里面很快会有你的私人内容）。
2. **每天写三行**（见 [`方案.md`](方案.md)）。写不出第二行就只写第一行。
3. **把仓库路径给 AI**，让它按 `方案.md` 的节奏读数据、出周报、登记预测。

不需要服务器，不需要数据库，不需要写代码。

---

## 三条硬规则

**1. 只收，不产出。**
系统一旦要求你"定期交一份总结"，它就会死。让 AI 产出，你只负责说。

**2. 定事件，不定时间。**
记录发生在"事情刚结束那一刻"，不是"每晚九点"。定时任务会变成又一个要启动的事。

**3. 允许断档。**
停电、没网、忙一天，都会断。**把断档当失败，这套东西三周就死。**

## 目录

```
.
├── 方案.md          每天怎么写、每周怎么复盘
├── index.md         索引：查东西从这页开始
├── daily/           你写的。一天一个文件，原话不改
├── profile/         AI 对你的理解
│   ├── 人格.md          你是什么样的人（稳定的）
│   ├── 处境.md          你现在什么状态（会变的）
│   └── 方向.md          悬着没决定的事 + 决策点
├── advice/台账.md   给过的建议 + 你到底做了没
├── memory/          长期记忆
│   ├── 事实.md          硬事实
│   ├── 预测.md          你说过的打算，到期对账
│   └── 沉淀/            可复用的经验
├── analysis/        周报、月报（AI 做，你只看）
└── notes/           AI 的工作笔记
```

---

## 隐私

**默认 private。**

这个模板里没有任何他人的个人信息。但你填进去的会有——家里的、身体的、钱的、面试失败的。

**要公开的话，只从 `memory/沉淀/` 里挑，永远不公开 `daily/`、`notes/`。**

---

## 一个最小的判断标准

如果你在想"要不要干脆做个 app"——先问三件事：

1. 查一件具体的事，手动翻文件超过 **5 分钟** 了？
2. 有 **3 个以上**的人想用？
3. 这套东西每周花你超过 **1 小时**？

三条都不到，就别做。**那不是在优化，是在推迟开始。**
